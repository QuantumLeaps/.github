# Security Policy

This is the default security policy for all repositories of
[Quantum Leaps](https://www.state-machine.com) that do not have their own
`SECURITY.md`.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub
issues, discussions, or pull requests.**

Instead, report them privately in one of these ways:

- email **security@state-machine.com**, or
- use GitHub's **"Report a vulnerability"** button on the repository's
  **Security** tab.

Please include the repository and version (or commit) affected, a
description of the problem and its impact, and the steps to reproduce it.
You will receive an acknowledgement within 5 business days.

Our full vulnerability disclosure policy, including what to expect after
you report, is at **https://www.state-machine.com/security/**

## Educational and Example Code

Some repositories (for example, video-course companions, articles, and
minimal demonstration kernels such as MiROS) contain educational code that
is not intended for production use. Reports about them are still welcome
and will be handled on a best-effort basis.

The production-quality products are QP/C, QP/C++, QM, and QTools. See their
repositories for the versions that receive security fixes.
